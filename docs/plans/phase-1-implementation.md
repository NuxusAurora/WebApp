# Phase 1 实施与验收

2026-11-08：用户最新指示为“做完 phase1 停下”。仅完成并验收 Phase 1，不实现 Phase 2。基线 703b397，单主代理，不推送。0001_baseline 不变。

## 解耦约定

- 用户模块拥有账户、一次性令牌、可撤销服务端会话；课程每次查询限定所有者，管理员也不绕过私人课程隔离。API 显式字段禁止客户端写角色、所有者、验证状态。
- 存储适配器拥有 S3 客户端、对象键和上传补偿；课程模块拥有文件元数据。仅接受 1 MiB 内 UTF-8 纯文本，拒绝二进制、控制字符、活动内容和已知恶意测试标记；这是受限文本内容检查，不是通用杀毒，不接受 PDF/图片。下载归属检查后签名 60 秒。
- Mailer 可替换；开发默认私有文件 outbox，生产显式配置 SMTP/STARTTLS。令牌不返回前端、不进日志，测试不向外部发邮件。
- UI → 同源白名单代理 → 认证/课程路由 → 数据库、邮件/存储。Argon2id 密码哈希；HttpOnly/SameSite Cookie、自定义头及 Origin 检查防 CSRF；请求体有上限。状态失败回滚，资源在 lifespan 关闭。
- 课程行锁串行上传与删除；账户行锁串行登录与密码变更，避免已失效凭据在并发时重新创建会话。

## 实施门禁

1. 新迁移 users/auth_tokens/courses/uploads；注册、邮箱验证、登录/登出、资料修改、密码修改/重置、课程 CRUD、上传及短期签名下载。

3. 验证两用户全接口隔离、令牌过期/重放/撤销、失败回滚/对象补偿、真实 PostgreSQL/S3 持久化；容器与生产构建、浏览器交互及响应式验收。
