## 解耦约定

- curriculum 领域拥有目录草稿、修订、确认、章节和小节；正式表只接收确认事务。Course.confirmed_revision 是并发基线。相同版本重复确认幂等；旧草稿不被重新生成覆盖。
- OCR 是可替换的本地异步适配器，图片经过 Pillow 解码、大小/像素/格式检查与重新编码后存入私有对象存储。Tesseract chi_sim+eng 安装在应用容器中；图片不发送模型，用户核对后的文字及教材上下文传给选定 Gateway。OCR 通过管道运行，单图 35 秒、整批 120 秒上限，超时/取消终止并回收子进程。
- 路由组合既有账户、课程所有权、存储和 Gateway；Gateway 不反向引用 curriculum。模型快照和调用审计复用 prepare；网络期间不持有课程锁，返回后重新核对所有权。workflow_runs 保存模型/Prompt/文字来源、成功原始输出及校验/失败/取消状态；版本关联 generation_run_id，编辑不覆盖来源，不写请求日志。
- 前端目录组件仅通过同源 API 读写；草稿与已确认快照分离。编辑、保存、确认是显式动作；移除项逐项展示并确认归档。切换课程/页签保护未保存内容，取消/卸载中止请求并拒绝过期响应。
- 正式 ID 通过显式引用保留，新节点采用 tmp- ID 并在确认中分配 UUID。重复/跨课程/跨父节点引用、过期修订及空标题全部拒绝；目录移除采用归档。Phase 4 知识点和学习状态未实现，不虚构依赖处理。
