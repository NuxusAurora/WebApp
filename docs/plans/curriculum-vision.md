# 目录图片直接识别

目标：绕过低质量本地 OCR，将显式选择的私有目录图片发送至所选视觉模型，以固定 Schema 生成待核对草稿。

- 通用 AI 契约新增有界、仅内嵌 PNG/JPEG 的图片输入；HTTP 适配器负责多模态编码，Gateway 拒绝无视觉能力的图片调用，继续统一校验与有界修复。
- 目录模块拥有图片所有权、读取顺序和提取 Prompt；图片模式不采用 OCR 文字为事实依据。网络前释放数据库，完成后重新检查课程/图片；审计与来源只记录图片 ID，不记录图片数据。
- 解析请求增加显式 images/text 模式，旧文字请求默认 text，保留本地 OCR 作为备用。图片 JSON 所有字段必需，未知页码为 null，无法辨认项进入 uncertain_items；只生成草稿，不自动确认。
- UI 显示图片发送范围，模型能力配置增加视觉开关。列表提示是否支持图片，未知能力不从名字推测。
- 先补失败回归：多模态请求、纯文字兼容、能力拒绝、固定 JSON Schema、图片所有权/失败无正式写入；再实现并验证前后端、生产构建及浏览器。
- 用用户本次提供的实拍图，通过已授权默认接口实际验收，预期可见 3 章/19 个子项；检查电脑贴纸未混入、起始页准确、结束页未知且未自动确认。测试课程/图片及临时模型仅按精确归属清理，用户原资料保留。
- 交付前对照以上职责与生命周期复查直接调用链，本地主分支按队列合入，不推送或部署云端。
