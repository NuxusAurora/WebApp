# Sidebar 重构 · 2026-11-09

当前 Next.js 16 / React 19，CSS 与自有 SVG 图标，无 UI 依赖。Workspace 读取 users/me 并持有用户/脏状态，三个主入口仅为内部 view；/system 单独复制了外壳，检查来自 ConnectionStatus。改造只覆盖外壳及直接调用链，保留业务组件、认证 API 和数据。

1. 合并为共享 AppSidebar：品牌、学习/设置导航、连接入口、真实用户菜单。深色沿用主内容主题，侧栏使用用户给定的克制色阶；浅色兼容。桌面 248/64px，平板默认收起，手机单一导航抽屉。
2. URL 为导航事实来源：沿用 / 与 /system，主入口以 /?view=ai、/?view=profile 区分；原 / 继续为课程。同步刷新、前进/后退和真实 aria-current，保留离开保护，避免重挂载外壳。不给未实现功能增加路由。
3. Sidebar 单独拥有折叠偏好、抽屉、账户菜单；Workspace 提供用户与导航/退出回调。偏好只保存非敏感折叠布尔值；失败回退内存。连接健康检查不进入 Sidebar，不伪造状态。System 复用 Workspace 外壳和原 ConnectionStatus。
4. 交互覆盖焦点恢复、菜单方向键、Escape、遮罩关闭、移动焦点限制、背景 inert 和减少动态。业务脏状态不会因折叠/抽屉开关丢失；退出/会话失效沿用既有 API 与清理。监听和滚动锁随生命周期解除。
5. 验证 URL/历史及未保存取消、偏好损坏/不可写、账户菜单/失败退出、移动导航收起、连接恢复；运行前端全套测试、TypeScript、生产构建和设计检测。实际浏览器检查课程列表/详情、模型/账户/状态、刷新和多尺寸；保留用户要求的前后运行截图。结束复查依赖边界并本地队列合入，更新 localhost:3000 前端，不推送/云端部署。
