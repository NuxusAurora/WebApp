# 模型知识生成与逐点学习

2026-11-09 最新用户决策：去掉搜索功能，直接使用模型自身知识（无需搜索服务）。这取代此前的自动联网检索与网页证据方案；文件路径沿用以保持已有链接。教材正文上传和粘贴仍不是必需步骤，完整依赖图谱后置。

## 当前阶段

按已确认的小节标题、学科、教材名、章节和相邻小节控制范围，直接使用启用模型的已有知识整理定义、学习目标、重要程度和掌握标准。按基础到应用排序；三档目标控制深度。教材名称与页码只是目录范围信息，不能假称已经读取教材正文。教材特有定义、符号和模型不确定事实保留在待核对项中，不虚构来源 URL、原文引文或联网核验记录。

用户只需选小节并生成，草稿保留编辑、一次小节级确认及正式 UUID 匹配；不要求逐点填写字段或配置搜索。失败、过期或替换冲突保留旧草稿，内容变化不能悄悄覆盖学习状态。界面与版本记录明确生成依据为模型自身知识和生成模型；这是生成追溯，不是事实核验保证。

## 解耦与兼容约定

- knowledge 拥有生成上下文、草稿、显式确认、正式知识点与版本。新增模型知识依据放在既有版本 source，正式读取只暴露来源类型、依据、模型名与 Prompt 版本；不向前端扩散完整生成上下文。
- Gateway 只适配模型协议及调用审计，不查询课程、不写领域数据；不增加 research、搜索密钥、抓取器或外部网页读取能力。模型服务是唯一外部推理依赖。
- 前端仅提交生成/编辑/确认命令并显示来源元信息；既有自动选模型、所有权隔离、草稿替换、正式 UUID 和学习状态保持兼容。
- 模型调用期间不持有课程锁，返回后重验归属、课程修订及标题/学科/教材/目标基线；失败、取消和冲突沿用现有工作流回滚/审计与前端切节中止、忽略迟到响应路径。本轮不将原非流式取消限制描述为已消除。

## 后续顺序

1. 模型知识生成：实现版本化 Prompt、相邻范围及依据追溯，保留核对和确认。按改动运行后端/前端回归、类型/格式、构建及实际浏览器/模型验收，未测质量明确记录。主代理复查本次职责、依赖与失败路径，解耦结论与测试分别报告。
2. 当前小节逐点学习：learning 拥有版本化会话、当前知识点和推进位置；一次加载当前点、必要先修和本会话历史。支持返回、暂停、刷新续学；打开内容或继续不等于掌握。
3. 节末测验：assessment 拥有题目映射、作答、反馈和重测历史。以本节已学习的正式知识清单版本出题，覆盖本节；标准答案在提交前不暴露。薄弱点回访和重测保留历史，MASTERED 继续由显式规则控制。
